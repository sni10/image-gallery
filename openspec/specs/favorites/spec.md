# favorites Specification

## Purpose
Личное «Избранное» пользователя: отметка понравившихся фото и раздел личного кабинета с их сеткой; признак избранного во всех ответах с фото.

## Requirements

### Requirement: Добавление фото в избранное
Система SHALL принимать `PUT /me/favorites/{photoId}` от вошедшего пользователя и отвечать `204`. Операция MUST быть идемпотентной: повторное добавление не создаёт дубликат и тоже возвращает `204`. Для несуществующего фото MUST возвращаться `404`, для анонима — `401`.

#### Scenario: Добавление
- **WHEN** вошедший пользователь отправляет `PUT /me/favorites/42` для существующего фото
- **THEN** ответ `204`, фото появляется в его избранном

#### Scenario: Повторное добавление
- **WHEN** фото уже в избранном и запрос повторяется
- **THEN** ответ `204`, в избранном одна запись этого фото

#### Scenario: Несуществующее фото
- **WHEN** `photoId` не существует
- **THEN** ответ `404`

### Requirement: Удаление фото из избранного
Система SHALL принимать `DELETE /me/favorites/{photoId}` от вошедшего пользователя и отвечать `204`, в том числе если фото не было в избранном или уже удалено. Для анонима MUST возвращаться `401`.

#### Scenario: Удаление
- **WHEN** пользователь удаляет фото из своего избранного
- **THEN** ответ `204`, фото больше нет в его избранном

#### Scenario: Фото не было в избранном
- **WHEN** пользователь удаляет фото, которого нет в его избранном
- **THEN** ответ `204`, ничего не меняется

### Requirement: Список избранного
Система SHALL отвечать на `GET /me/favorites?page=&limit=` вошедшему пользователю `200` с `{ "items": Photo[], "total": <число> }`, где фото идут от недавно добавленных к давним. Пагинация MUST работать по тем же правилам, что у остальных списков: `page` с 1, `limit` по умолчанию 20 и не больше 100, страница за пределами `total` даёт пустой `items`, неверные параметры дают `400`. Каждый пользователь MUST видеть только своё избранное. Для анонима MUST возвращаться `401`.

#### Scenario: Сетка избранного
- **WHEN** пользователь добавил фото A, затем B и запрашивает `GET /me/favorites`
- **THEN** ответ `200`, `items` содержит B, затем A, `total` равен 2, у обоих `isFavorite: true`

#### Scenario: Чужое избранное недоступно
- **WHEN** пользователь X запрашивает `GET /me/favorites`
- **THEN** в ответе нет фото, добавленных в избранное пользователем Y

#### Scenario: Удалённое фото
- **WHEN** фото из избранного удалено из галереи
- **THEN** оно пропадает из `GET /me/favorites`, `total` уменьшается

### Requirement: Признак избранного в ответах с фото
Каждый объект `Photo` во всех ответах API (`GET /photos`, `GET /galleries/{id}/photos`, `cover` в галереях, `GET /me/favorites`) SHALL содержать булево поле `isFavorite`. Для вошедшего пользователя оно MUST показывать, есть ли фото в его избранном; для анонима MUST быть `false`.

#### Scenario: Вошедший пользователь смотрит галерею
- **WHEN** пользователь, добавивший фото 42 в избранное, запрашивает фото его галереи
- **THEN** у фото 42 `isFavorite: true`, у остальных `false`

#### Scenario: Аноним
- **WHEN** аноним запрашивает любой список фото
- **THEN** у всех фото `isFavorite: false`
