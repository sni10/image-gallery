## Purpose

Фильтр общей ленты фото по тегу: главная сайта показывает только фото с выбранным тегом.

## ADDED Requirements

### Requirement: Фильтр ленты фото по тегу
`GET /photos` SHALL принимать необязательный параметр `tag`. Если он задан, ответ MUST содержать только фото, у
которых этот тег есть, в том же перемешанном порядке по `seed` и с той же пагинацией (`page`, `limit`, `total`).
Без `tag` ответ MUST оставаться прежним.

#### Scenario: Фото с тегом
- **WHEN** запрошен `GET /photos?seed=abc&tag=cat`, а тег `cat` есть у фото A и B из разных галерей
- **THEN** ответ 200, в `items` только A и B, `total` равен 2

#### Scenario: Порядок и страницы как у общей ленты
- **WHEN** фото с тегом запрашиваются по страницам с одним `seed`
- **THEN** страницы вместе содержат каждое такое фото ровно один раз, и при том же `seed` порядок не меняется

#### Scenario: Без параметра
- **WHEN** запрошен `GET /photos?seed=abc` без `tag` или с пустым `tag=`
- **THEN** ответ такой же, как до изменения: все фото

### Requirement: Нормализация тега в запросе
Значение `tag` MUST нормализоваться так же, как теги при загрузке фото: пробелы по краям и ведущий `#` убираются,
регистр приводится к нижнему.

#### Scenario: Регистр и решётка
- **WHEN** запрошен `tag=%23Cat`
- **THEN** ответ совпадает с ответом на `tag=cat`

### Requirement: Неизвестный тег
Тег, которого нет ни у одного фото, MUST давать пустую страницу, а не ошибку.

#### Scenario: Нет таких фото
- **WHEN** запрошен `GET /photos?seed=abc&tag=nothing`
- **THEN** ответ 200, `items` пустой, `total` равен 0
