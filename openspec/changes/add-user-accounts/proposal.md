## Why

Сейчас галерея анонимная: посетитель может только смотреть фото. Нужны учётные записи, чтобы человек мог собирать понравившиеся картинки в «Избранное» и возвращаться к ним с любого устройства. Это основа для будущих персональных функций.

## What Changes

- Регистрация по email и паролю. Аккаунт становится активным только после перехода по ссылке из письма подтверждения; письмо можно запросить повторно.
- Вход по email и паролю с выдачей JWT (короткоживущий access + refresh). Обновление access по refresh, выход с отзывом refresh-токена.
- Личный кабинет, раздел «Личная информация»: просмотр своего email, смена email с подтверждением на новый адрес, смена пароля с вводом текущего.
- Личный кабинет, раздел «Избранное»: сетка избранных фото с постраничной подгрузкой; добавление и удаление фото из избранного.
- В ответах с фото (`Photo`) появляется поле `isFavorite`: для вошедшего пользователя — отмечено ли фото, для анонима — всегда `false`.
- Отправка писем через SMTP, настраиваемый через env; в разработке письма выводятся в консоль.
- Ограничение частоты запросов на вход, регистрацию, повторную отправку письма и смену пароля.
- Публичные эндпоинты галереи остаются доступными без авторизации. **BREAKING (мягкое):** если клиент пришлёт просроченный или неверный JWT даже на публичный эндпоинт, ответ будет 401 — фронт должен обновить токен или убрать заголовок.

Вне рамок изменения: восстановление забытого пароля, вход через соцсети, имя/фамилия/аватар в профиле, удаление аккаунта.

## Capabilities

### New Capabilities
- `user-auth`: регистрация по email, подтверждение email по ссылке, повторная отправка письма, вход с выдачей JWT, обновление и отзыв токенов, ограничение частоты запросов.
- `user-profile`: просмотр данных текущего пользователя, смена email с подтверждением, смена пароля.
- `favorites`: добавление/удаление фото в избранное, список избранного с пагинацией, признак `isFavorite` в ответах с фото.

## Impact

- **Бэкенд (этот репозиторий):** новое Django-приложение `accounts` (регистрация, вход, профиль, письма); модель `Favorite` и эндпоинты избранного в `gallery`; `PhotoSerializer` получает `isFavorite`; новая секция настроек почты и адреса фронта в `config/app_settings`; настройки DRF (аутентификация JWT, throttling); модель refresh-токенов; миграции; OpenAPI-спецификация расширится.
- **Зависимости:** `PyJWT` — подпись и проверка access-токенов. Refresh-токены хранятся в собственной таблице, без сторонних Django-пакетов для JWT.
- **Инфраструктура:** нужен SMTP-сервер для продакшена; новые переменные в `.env`/`.env.example` и `compose.yaml`.
- **Фронтенд (`image-gallery-front`, отдельный репозиторий):** страницы регистрации, входа, подтверждения email (по ссылке из письма), личного кабинета с двумя разделами; хранение и обновление токенов; кнопка «в избранное» в сетке/лайтбоксе.
- **Данные:** существующие пользователи (суперпользователь админки) продолжают работать; админка остаётся на сессиях Django и не зависит от JWT.
